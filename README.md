# 🖨️ 3D Printer Fault Detection using Machine Learning

A Machine Learning based web application that detects faults in a 3D printer using vibration sensor data from X, Y, and Z axes.

## 🚀 Features

* Real-time fault prediction
* Logistic Regression based ML model
* SMOTE data balancing for better accuracy
* Interactive Flask web interface
* Sample test values for quick testing
* Probability-based fault detection system

## 🛠️ Technologies Used

* Python
* Flask
* Scikit-learn
* Pandas & NumPy
* HTML, CSS, JavaScript
* SMOTE (Imbalanced-learn)

## 📊 Working

The system takes vibration/movement sensor values from the 3D printer and predicts whether the printer is working normally or showing signs of faults.
